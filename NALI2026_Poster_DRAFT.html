Learn2Unlock: Turning Screen Time Into
Curriculum-Aligned Learning Time

A parent-governed mobile system where children earn device access by answering KSSR-aligned questions — and where generative AI drafts questions but never scores, never rewards, and never reaches a child unapproved.

The Problem

Parental control tools respond to children's device use almost entirely with restriction — timers, blocklists, bedtime cut-offs. Restriction is adversarial by design: it makes the parent an obstacle, produces daily negotiation, and teaches the child nothing. The time spent unlocking a device produces no educational value.

A small category of "answer-to-unlock" apps exists, but fails in practice for three reasons:

Content mismatch

Generic question banks that rarely map to the national curriculum a Malaysian child is actually assessed on.

Authoring burden

Where parents can add questions, they must write, verify and maintain them by hand — unrealistic for working parents.

Trust gap

Where AI generates questions, it does so unsupervised. Parents cannot see, correct or veto what their child is shown.

Objectives

  1. Make device access earned through curriculum practice, not granted or denied arbitrarily.
  2. Cut parental authoring effort with generative AI while keeping every question under human control.
  3. Enforce architecturally that AI cannot score attempts, change rules, or award time.
  4. Ship a cross-platform prototype covering KSSR Years 1–6 in four subjects.
  5. Define an evaluation measuring engagement and reduction in screen-time conflict.

Innovation & Novelty — Where the AI Sits

The novelty is not the reward loop. It is that the model is confined to drafting only. Scoring, reward calculation and rule enforcement live in deterministic server code the model cannot reach.

System Architecture

Parent App

Expo · React Native · TS
  • Five-step family setup
  • Question bank & manual authoring
  • AI generation & review queue
  • Time-request approvals
  • Progress reports

API Server

Node.js · SQLite · Zod
  • Token auth with expiry
  • Attempt scoring (deterministic)
  • Reward ledger & daily caps
  • Safety filter pipeline
  • Provider key never leaves server

Child App

Expo · React Native · TS
  • Restriction notice
  • Multi-question challenge
  • Pass/fail & earned time
  • Request more time from parent
  • Always-on emergency access

Separate apps, not one app with a PIN. The child's device runs the child app; the parent keeps a genuinely separate control surface with its own authentication and visual language. A shared package holds theme tokens, Zod schemas, repository contracts and the KSSR-aligned seed bank.

Safety Filter

Before a parent sees a draft, the server rejects it if:

✕It contains blocked terms — personal-data solicitation or unsafe content
✕The stated correct answer is absent from the options
✕Options duplicate after normalisation
✕The explanation does not contain the correct answer
✕It duplicates a question already in the bank

Parent review time is spent on judgement, not on catching obvious errors.

Impact & Potential

  • Educational. Time already spent negotiating for devices is redirected into spaced retrieval practice on the exact standards the school assesses.
  • Social. The parent shifts from gatekeeper to curator — shaping what a child practises in minutes of review rather than hours of tutoring.
  • Market. Malaysian households with primary-school children, reached via schools, PIBG networks and tuition centres.
  • Scale. A school licence lets one teacher approve a bank for many families.
  • Transferable. Curriculum-agnostic — swapping the learning-standard taxonomy adapts it to other national curricula.

Conclusion

Generative AI can be introduced into children's educational technology without asking families to trust an unsupervised model. By confining the model to drafting, filtering its output deterministically, and requiring explicit parental approval before any question reaches a child, Learn2Unlock captures the scale advantage of AI content generation while keeping authority entirely human. A working prototype is complete; the planned pilot will test whether the approach delivers measurable engagement gains and reduced household conflict.
