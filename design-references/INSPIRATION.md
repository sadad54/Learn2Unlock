# Inspiration notes

These references informed interaction patterns and information hierarchy only. The Learn2Unlock visual language, mascot, layouts, and copy are original.

- [Google Family Link](https://play.google.com/store/apps/details?id=com.google.android.apps.kids.familylink): child-first dashboard structure, daily limits, app-level controls, and clearly separated always-allowed apps.
- [Qustodio parent app](https://help.qustodio.com/hc/en-us/articles/360005451278-What-is-the-Qustodio-Parents-App-and-how-do-I-use-it): mobile-friendly parent summaries, activity reporting, and fast access to common controls.
- [Khan Academy Kids](https://en.khanacademy.org/kids): joyful learning tone, friendly character guidance, and large direct actions for early learners.
- [Duolingo ABC](https://www.duolingo.com/abc): bite-sized learning flow, playful progress feedback, and simple character-led encouragement.
- [Dribbble kids-learning exploration](https://dribbble.com/shots/27022070-Kids-Learning-Mobile-App-UI-Design): contemporary subject cards and colorful learning-progress treatments, used only as broad visual calibration.

## Learn2Unlock-specific decisions

- Parent actions stay dense but never hide consequences: remaining time, rule caps, request details, and protection status are visible before action.
- Child screens always reveal the complete exchange before a challenge: question count, passing score, reward, and next free-play time.
- Locked states use “paused” language and always offer a constructive next step.
- Color never carries state alone; labels such as Protected, Pending, Locked, and Challenge passed remain visible.
