# Learn2Unlock UI reference images

This set contains 19 mobile reference screens at 390 × 844 logical pixels (exported at 2× resolution): 13 parent-app screens and 6 child-app screens.

## Visual direction

- Parent app: deep navy control surfaces, compact cards, turquoise actions, amber attention states.
- Child app: warm cream canvas, large teal controls, visible reward requirements, encouraging language.
- Signature: a continuous “time path” motif used in countdown rings, progress tracks, onboarding steps, and charts.
- Accessibility baseline: 44–48 pt touch targets, text labels alongside color states, high-contrast body copy, and one primary action per screen.

Open `index.html` to view the complete gallery. Individual PNG exports are in `screens/`.

The original mascot was generated with the built-in image-generation tool and composited into deterministic HTML/CSS screen layouts. `assets/milo-mascot.png` is the transparent project asset; `assets/mascot-chroma.png` is the unprocessed source.
